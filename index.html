Test your skill

Two ways to test — choose based on your skill type.

✓ Prompt test works for Text-only skills — writing, analysis, documentation, code review, formatting
⚠ Not sufficient for Skills with scripts, external APIs (Jira, Snowflake, Google), database connections, real data, or multi-step agentic workflows — use local install + evals for those
A — Quick prompt test (text-only skills)
Response
📄 Skill context sent to Claude as system prompt
B — Install to local machine (skills with scripts, APIs, evals, real data)

Push your skill first to create a branch, then come back here to install it locally for full testing.
